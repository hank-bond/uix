# Documentation contribution practice

Place information before classifying or styling a document. For an ordinary documentation change, choose the narrowest owner and document form first, apply the prose guidance second, then regenerate and verify the indexes. Consult the structural model when proposing a change to that practice or when the practice leaves a gap.

Tree-specific authoring specs remain with the trees that they govern. They refine this repository-wide practice rather than duplicating it.
